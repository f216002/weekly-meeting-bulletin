# 每週會議快訊（正式站）

正式網址（GitHub Pages）：https://f216002.github.io/weekly-meeting-bulletin/

這是每週點傳師週會紀錄的公開快訊站，第一版內容來自 2026 年 10 月 27 日週會紀錄（對話中上傳本），表頭依 Cheng 指定只寫「2026年10月28日」一行（會議本身是 10 月 27 日，差異見 RULES.md 第 0 節）。

## 本站是什麼

- 一事件一卡：一個議題子項一張卡，同日期不同事件也要分卡。
- 去敏感化公開版：線上會議帳號密碼、個人電話、聯絡信箱、清口與安堂個人名單、各區出席大表皆不在本站公開。
- 首頁永遠只顯示最新已發布的一週，舊週進存檔。
- 白底黑字、彩色邊框（A 紅、B 橘、C 灰藍），每張卡有分享圖片與複製文字，方便傳到 LINE 群。

## 每週怎麼操作

1. Cheng 把當週主檔放進 Drive 輸入資料夾對應的週夾（資料夾 ID 見 config.json，結構見 RULES.md），或以後備方式放進本倉庫 `input/` 資料夾並推送。
2. 程式依 RULES.md 第 5 節遞迴選出最新主檔，產生草稿；草稿絕不自動發布。
3. Cheng 在草稿檢查、編輯、刪除，確認後才發布到首頁；沒有確認時首頁繼續顯示上一週。
4. 發布後按卡片分享圖片傳到 LINE 群。

注意：Drive 自動讀取仍需 Cheng 完成分享／憑證設定（把資料夾分享給執行 Action 的帳號，並把憑證放進 GitHub Secrets，絕不在程式碼或文件中放密碼）。在該設定完成前，請用 `input/` 後備方式。不要把資料夾設成公開連結，也不要向任何人索取密碼。

## 檔案說明

- `index.html`：本週公開頁（由 `weeks/2026-10-28.json` 生成）。
- `weeks/*.json`：每週已發布資料。
- `scripts/select_newest.py`：最新主檔判斷程式（含自測，不需網路與憑證）。
- `RULES.md`：拆卡、分類、完整、去敏感化、最新檔判斷、發布閘門的完整規則。
- `config.json`：Drive 資料夾 ID 與結構說明（只有 ID，沒有憑證）。
- `.github/workflows/generate-draft.yml`：推送到 `input/` 時產生草稿並跑自測，不自動發布到首頁。
